# Project workspace extension
Mode: Operate. Authenticated administrators inspect Trade City and navigate Code City projects.

## Direction contract
THESIS: A private project entrance that opens onto a portfolio-led reporting workspace. Project navigation and the fixed-code gate precede financial data.
OWN-WORLD: Inherit the portal's navy surfaces, warm white type and precise thin boundaries; use restrained amber for project actions and chart ink, with a pale portfolio panel for contrast.
STORY: Sign in, unlock using the owner code, choose Trade City, then inspect recorded performance and positions. Missing data is visibly unavailable.
FIRST VIEWPORT: Persistent Code City navigation at left; Trade City title and account control above a wide realized-performance chart; open portfolio and Nova at right; positions below. A keyboard-operable scrubber explores recorded closes.
FORM: Portfolio-first extension of the existing portal. Owner preference question was offered; no answer received before implementation, so this is a session assumption, not a stored aesthetic preference. No generated-image workflow used; the reporting interface is native DOM and geometric chart SVG.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No new raster assets. The existing Trade City logo is reused; no marketing claims or live balances are fabricated. Review captures use a separate, clearly labelled synthetic-data fixture.
