# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Code City administrators and the owner access ORC and Trade City through the private admin entrance.

## Product Purpose
Provide one email/password account entrance, followed by a choice of ORC or Trade City and a separate owner-set fixed access code for each project.

## Capabilities and Constraints
Preserve Supabase authentication, password setup/reset, authorization and project-code checks. Preserve the Code City public website and native Mac apps. Cloud hosting remains the intended runtime; the sign-in design must not imply that incomplete workspace deployment or email delivery is verified.

## Brand Commitments
Code City name and existing logo; canonical ORC and Trade City app icons. The owner requests a chic, clean, futuristic sign-in page and delegates visual decisions. This request is scoped to /sign-in.

## Evidence on Hand
Existing Login.jsx/AuthProvider.jsx, canonical public/brands/orc-app.png and trade-city-app.png, and the current deployed sign-in page. No new performance or security marketing claims are authorized.

## Product Principles
Preserve working authentication. Make the primary task obvious. Keep public marketing and project runtime changes outside this visual task. Use real project assets.
